# BioMirror v3 — Python Requirements
# Compatible: Python 3.10, 3.11, 3.12, 3.13 | Windows 10/11 | CPU-only
#
# INSTALL ORDER:
#   1. Everything below (this is now everything the LIVE SERVER needs —
#      matplotlib/optuna were moved out, see the OPTIONAL section at the
#      bottom, they're not required to run the app):
#      pip install -r requirements.txt
#   2. PyTorch (optional — enables PINN prediction; app runs fine without
#      it, falling back to the Bergman physics engine):
#      pip install torch --index-url https://download.pytorch.org/whl/cpu
#
# SLOW/UNRELIABLE NETWORK NOTE:
#   If pip is timing out or backtracking through old package versions
#   (visible as many "Retrying... Read timed out" lines, followed by pip
#   trying progressively older versions of a package), that's a network
#   reliability issue, not a requirements.txt problem. Two things help:
#     pip install -r requirements.txt --timeout 120 --retries 10
#   and installing the slow/large packages on their own first so a single
#   dropped connection doesn't restart the whole batch:
#     pip install numpy pandas scikit-learn scipy
#     pip install -r requirements.txt
#
# PYTHON 3.13 NOTE:
#   pydantic==2.7.1 fails on Python 3.13 Windows (no pre-built wheel).
#   Use pydantic>=2.8.0 instead — same API, has Python 3.13 wheels.
#
# PHASE 2 NOTE: the live API optionally loads a trained PINN model
# (models/biomirror_pinn.pt) for near-term glucose prediction, via
# backend/ai_bridge.py. Torch is not a hard requirement — if it's not
# installed, or no checkpoint is found, /forecast and /metrics
# automatically fall back to the Bergman-only physics engine. See
# backend/ai_bridge.py's module docstring for the honest caveat on
# current model quality.
